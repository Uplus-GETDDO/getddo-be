# 실제 실행 보고서

실제 테스트를 실행한 뒤 [검증 결과 양식](../../templates/verification-report.md)을 복사해 이 폴더에 보고서를 추가합니다. 현재 이 PR에는 실제 실행 결과 보고서를 등록하지 않았습니다. 기존 README·Wiki의 과거 결과와는 별개입니다.

## 작성과 등록

1. 파일명은 `YYYY-MM-DD-주제.md`로 작성합니다. 같은 날 별도 실행은 `-02` 등으로 구분합니다.
2. 실제 실행 조건·명령·기대값·실제값·판정과 한계를 기록합니다. 템플릿의 검사 항목은 선택용 예시이며 검증 범위에 맞게 바꿉니다.
3. 필요한 작은 요약 JSON·CSV는 [assets 폴더](assets/README.md)에 넣고 보고서에서 상대 경로로 연결합니다. HTML·XML·대용량 로그의 외부 보관 위치도 적습니다.
4. 복사한 양식의 근거 파일 안내 링크는 `assets/README.md`로 바꿉니다. 실제 보고서 안의 모든 상대 링크를 확인합니다.
5. 아래 목록에 실제 보고서 링크와 검증 범위·핵심 결과를 추가합니다. README·Wiki에는 필요한 요약과 해당 보고서를 연결합니다.

### 개발 서버 설정 읽기 전용 확인

- EC2 Instance Connect Endpoint를 거친 SSH로 API 서버 한 대에 접속해 값만 읽었다. 바꾼 값은 없다. 컨테이너와 이미지, 환경 파일의 설정 이름을 확인했고 비밀값은 기록하지 않았다.
- `RATE_LIMIT_STORE=redis`이고 Redis 연결은 TLS가 켜져 있다. 요청 제한 정책 값은 별도로 덮어쓴 것이 없어 코드 기본값(사용자 20회, 이벤트 10회, 1분)이 적용된다. 플래티넘 확률도 덮어쓴 값이 없어 코드 기본값 2bp(0.02%)다.
- 서버 시계는 AWS 시간 서비스와 동기화되어 있다(오프셋 거의 0). Flyway 최신은 V029(플래티넘)이고 `abuse_cases`는 옛 구조라 GD-144(PR #159)와 V030은 아직 배포 전이다.
- DB(MySQL 8.4.11): 전역 격리 수준 REPEATABLE-READ(응모 기록은 READ_COMMITTED로 실행), `innodb_lock_wait_timeout` 50초, `max_connections` 60, 시간대 UTC. 응모권은 읽기 전용 세션으로 집계해 브론즈 97, 실버 19, 골드 0, 플래티넘 0이었다. 플래티넘이 아직 나온 적이 없다.
- API 서버는 A·C 두 대가 ALB 뒤에 있다. Redis 설정은 한 대만 직접 확인했고 다른 한 대는 같은 설정으로 본다.

# API 구현 검증 항목

- 상태: 검토 대기 — 담당자 확인 전

아래는 향후 업무 API 구현 시 검증할 시나리오이며 실행한 테스트 결과가 아니다. 공개 요청·응답 계약은 `getddo-spec/05-api`를 따른다.

| 영역 | 확인할 시나리오 |
| --- | --- |
| 헤더·권한 | ID 없음/UUID 오류/미등록 ID, 멤버십 불일치, 헤더 역할값으로 DB 역할 덮어쓰기 금지, 관리자 응모 거절, 선택된 사용자 문맥 밖의 개인 정보·알림 접근 거절. ID 선택 자체는 인증이 아님 |
| 공통 | 실패 시 HTTP 상태·봉투 일치, 페이지 1 시작, 커서 재조회 정렬 안정성, 시각 오프셋·KST 업무일 경계 |
| 이벤트 | 경품 없는 등록·중복 등수 거절, 이벤트/경품 함께 rollback, 시작 앞당김·중단/진행/종료 후 제목 수정 거절 |
| 이벤트 운영 | 응모와 중단·취소 경합, 중단 후 마감 자동 취소, 취소와 반환 함께 완료, 동시/반복 취소 중복 반환 방지 |
| 응모 | 응모권 미사용 1회, 가중치 미적용은 브론즈 1장만(다른 등급은 거절)·1회, 일반 가중치는 누적 5장(3장 사용 후 2장 가능/3장 거절), 등급별 보유 초과 거절, 동시 누적 상한·보유량 초과 방지, 응모 요청 형식 오류와 관리자·멤버십 거절 |
| 멱등 | DB 확정 후 연결 끊김 재시도, 같은 키 다른 본문, 마감 후 동일 요청 재조회, 새 응모와 재전송 구분 |
| 마감 | 정확한 마감부터 거절, 요청은 마감 전이나 DB 확정이 마감 이후인 응모, 응모권 만료 경계 |
| 출석 | KST 자정·월초, 누락 후 연속 초기화, 같은 달 같은 단계 중복 미지급, 동시 출석과 보상 원자성 |
| 미션 | 도착은 종료 전/검증은 종료 후 인정, 종료 시각 도착 거절, 필수 답변 누락, 정답 정보 노출 금지, 완료 후 답변 불변·보상 1회. 퀴즈 문항별 정답 누적과 이미 맞힌 문항 재전송 무시, 같은 제출 ID 재전송 200·다른 본문 409, 같은 사용자 동시 완료의 보상 1회 |
| 게임 | 서버 점수 검증, 같은 playId 결과 재사용, 처리 중 202, 무효 결과 점수/보상 제외, 게임별 일일 보상 1회·정책 변경에도 유지 |
| 응모권 | 지급·반환의 다른 만료일(반환은 다다음 달 1일), 실제 잔여분만 만료, 등급별 장수 선택 차감(같은 등급은 만료 이른 순, 보유 초과 거절), 같은 응모 재호출은 기존 결과 재생, 동시 반환은 한 번만 반영, 반환 재요청 중 응모권이 다시 쓰여도 기존 결과 재생, 서로 다른 사용자의 동시 차감·반환 교착 없음, 원본별 만료 중복 차감 방지, 이벤트 취소 시에만 반환(추첨 제외 반환 없음), 회수 API·처리·알림 경로 부재 |
| 추첨 | 미검토 의심 포함, 실행별 결과 1개, 동일 사용자 중복 당첨 금지, 상위 등수부터 배정, 응모자 없음/후보 없음/자리 부족 구분 |
| 발표 | 마감 +1분 자동 추첨과 관리자 확인·수동 공개 구분, 공개 전 모든 응답에서 결과 은닉, 실패 시 미확정 결과 공개 금지, 서버 시각과 공개 상태 기준 |
| 재추첨 | 확인된 당첨 취소만 허용, 기존 당첨자 유지, 원래 낙첨자·가중치 사용, 동일 취소 중복 실행 방지, 관리자 확인 전 새 결과 은닉 |
| 알림 | 시작 10분 전 1회·자격 판정, 일정 변경 수신자 안내, 실제 공개 후 결과 알림, 변경 대상자만 안내, 재시도 중복 생성 금지 |
| 알림 읽음 | 목록 조회로 읽음 변경 없음, 본인만 개별/전체 읽음, 읽음 시각 없음, 모의 발송과 독립 |
| 관리자 | 조회·필터·페이지, 정책 다음 KST 일/월 적용, 임의 잔액 수정/사용자 정보 수정 경로 부재, 이력 보존 |
